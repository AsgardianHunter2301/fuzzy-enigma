# Deploy COMP2521 Tracer

Extract this ZIP into a new folder and open `index.html`. Keep the supplied folder structure and all files under `assets/`.

The runtime uses bundled assets only. Optional community links need internet access when opened. A browser policy may restrict local-file execution; in that case use a local or approved static web host.

For a smoke check, open a topic and choose Tools, then System check. Full regression tests and the outstanding human checks are in the separate assurance package.

Publish only the classroom distribution after approval. Do not publish assurance evidence, test fixtures or predecessor archives. Copying files over an older deployment does not remove stale files.
