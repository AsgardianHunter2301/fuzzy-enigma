# Manual Boundary Guide

The app separates three cases.

1. Exact manual C
   The C is printed in the 26T2 manual.

2. Manual pseudocode
   The pseudocode is printed in the manual. The side-by-side C is a study conversion and is not printed in the manual.

3. Outside the manual
   The knowledge or C is outside the manual and must be learned separately.

Mandatory warning for supplemental C:

`This C is supplemental. Learn it separately.`

The 26T2 course outline describes the final exam as closed-book with relevant documentation supplied. Confirm the exact supplied documents in the current exam instructions.
