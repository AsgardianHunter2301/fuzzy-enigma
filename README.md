# COMP2521 Tracer

Open `index.html` in a modern browser.

Everything required to run the tracer is included in this folder, including `assets/tracer-core.js`. No external JavaScript, server or internet connection is required. Optional community links need internet access only when opened.

## Start

1. Search for a topic.
2. Review or edit the example inputs.
3. Press `Run` or `Run example`.
4. Use Source, Trace and State together.
5. Use the timeline or Left and Right arrow keys to move through exact algorithm steps.

## Source labels

- Manual: exact 26T2 manual C or pseudocode.
- Lecture: supplied lecture material.
- Memorise: complete C is not printed in the manual or lecture.
- Named only: the course names the item but the supplied material is not sufficient for a faithful trace.

## Theme

Use Dark mode on the home page or under Tools. Use system theme restores automatic switching. Explicit choices are retained when browser storage is available.

## System check

Open any topic, choose `Tools`, then `System check`. The check confirms the bundled core, topic registry, renderers, local runtime assets and current topic. It is a classroom smoke check, not the full assurance suite.
